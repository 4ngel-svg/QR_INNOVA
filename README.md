# QR INNOVA

Generador de QR permanente para WhatsApp. Al escanearlo se abre el chat con el
mensaje ya escrito.

**Úsalo aquí:** https://4ngel-svg.github.io/QR_INNOVA/

- Funciona en iPhone, Android y computadora, desde el navegador.
- El QR es fijo: lleva dentro el enlace `https://wa.me/<número>?text=<mensaje>`,
  así que no caduca ni depende de ningún servidor.
- Todo se genera en tu propio dispositivo; no se envía ningún dato.

Toda la página está en `index.html` (un solo archivo, funciona sin internet).
